# 36편 가이드 가독성·출처·탐색 개선 검수

검수일: 2026-10-01. 기존 6개 주제와 36개 가이드 주소를 유지했다. 글 수를 늘리거나 검색·필터 조합을 새 검색 노출 페이지로 만들지 않았다.

## 요청별 변경

1. 36편 각각에 주제별 설명 2개 절, 6개 문단을 추가했다. 총 72개 절·216개 문단이며, 객실 상품 대조, 혼자 주문하는 동선, 교통 환승, 귀가편, 비용 단위, 변경 계획처럼 서로 다른 방문 문제를 다뤘다.
2. 글 첫머리의 짧은 답, 확인 순서, 본문 소제목, 상황 비교표, 가상 예시, 문의 질문, 공식 자료, 관련 글 순서로 편집했다. PC는 옆 목차, 모바일은 상단 목차와 한 열 본문을 사용한다. 본문은 모바일 16px 이상, 줄 높이 1.85, 문단별 간격을 두고 한국어 단어 중간 끊김을 줄였다.
3. 데이터 읽기의 '수정 원칙', '최초 발행본', 수집일 보존을 설명하는 작업 문구를 삭제했다. 가이드마다 반복되던 작성 방법·내부 판단 메모를 화면에서 덜어냈고, 비교표의 작성자 지시형 표현을 방문자가 취할 행동으로 고쳤다. 소개 페이지도 제작 절차 나열 대신 자료 이용 안내와 실제 문의 방법으로 정리했다.
4. 모든 가이드에 한국관광공사 공식 데이터 페이지와 대한민국 구석구석을 연결하고, 주제에 따라 기상청·코레일·주소정보누리집·국가동물보호정보시스템·KISA를 추가했다. 총 83개의 공식 자료 링크다. 링크가 가리키는 자료의 범위를 설명하고, 준비 제안을 기관의 공통 규정인 것처럼 표시하지 않는다.
5. 관련 글 108개 연결을 유지하고 이전·다음 글 70개 연결, 전체 가이드 복귀, 공통 하단의 6개 주제 링크를 추가했다. 필터 때문에 목적지 구역이 사라진 경우에도 카테고리 이동 시 목록을 복원하도록 수정했다.

## 분량 산정

- 공백 제외 본문: 편당 최소 1,362자, 최대 1,647자, 합계 54,644자.
- 포함: 도입, 확인 순서의 설명, 추가 본문 문단, 가상 사례 설명, 문의 질문.
- 제외: 제목, 목차, 핵심 답 요약, 표, 출처 설명, 반복 안내, 관련 글, 이전·다음 글, 메뉴·하단.
- 원고의 글자 수와 서버가 실제 출력한 36편 본문이 같은지 대조했다. 긴 문단 중복도 검사했다.
- 1,300자는 이번 사용자 요청의 검수 기준이다. Google의 검색 노출 또는 AdSense 승인 최소 글자 수라고 주장하지 않는다.

## 사실과 범위 보존

- 실제 조사 표본은 2026-09-26 수집 자료 12곳 그대로다. 이번 문장 편집일을 현장 확인일로 바꾸지 않았다.
- 가상 예시는 실제 방문 후기나 실제 업장 요금이 아니라고 구분한다. 동반 허용, 실시간 운영, 좌석·객실 재고, 건강·법률 조건을 새로 만들어 넣지 않았다.
- 원자료·해석·남은 질문, 표본의 한계, 사진 이용조건은 유지했다. 불필요한 제작 설명 삭제가 사실 확인의 한계 은폐가 되지 않도록 했다.
- 출처 페이지에 공공데이터포털의 '실시간' 표기와 보관된 매뉴얼의 '일 1회' 안내를 구별했다. 어느 쪽도 개별 시설의 현재 입장을 보장하지 않음을 설명한다.
- API 호출 구조, Worker 비밀키 처리, 45개 승인 canonical URL 목록, 검색·계획 화면의 noindex 정책은 변경하지 않았다. 내용이 실제 바뀐 데이터 읽기·출처 페이지의 수정일만 갱신했다.

## 실행 검사

- PASS: `npm run typecheck`.
- PASS: `npm run build`. 기존 Vite 실험 API 안내와 텍스트 경로의 빈 클라이언트 청크 안내는 오류가 아니다. 빌드 후 로컬 비밀 파일 제거 완료.
- PASS: `npm run test:editorial`. 36편 본문·공식 출처·Article 인용·이전/다음 링크·404·검색 매개변수 noindex 검사.
- PASS: 같은 검사에서 360·390·768·1280px의 대표 8개 화면, 가이드 검색·빈 결과·주제 이동·질문 복사·문의 초안·키보드 이동. 가로 넘침, 자동 접근성 위반, 실행 오류 0건. PC·모바일 스크린샷 직접 확인.
- PASS: `npm run test:links`. JavaScript를 끈 상태에서 공개 화면 46개, 사이트맵 45개 주소, 내부 링크 2,020개 검사. 고립된 페이지 0개. 어느 검사 대상 페이지에서든 다른 공개 페이지까지 최대 2회 링크 이동.
- PASS: `npm run test:publisher`. 실제 목록·상세·주변·페이지 나누기 API와 잘못된 입력·허용하지 않은 메서드, 검색·비교·공유·빈 결과·오류 화면, SSR HTML·metadata·robots·sitemap 검사.
- PASS: `npm run test:value`. 비용 계산, 실제 표본 무결성, 원문과 해석, 문의 기능. 마지막 비교표 문장 수정 전 실행했으며 관련 계산·문의 구현은 변경하지 않았다.
- PASS: `npm run test:adsense`. `ads.txt`, 서버 HTML의 pub 코드, 페이지 이동 후 광고 격리 검사.
- PASS: `npm run test:private`. 비밀 파일 추적 여부, 실제 로컬 비밀값의 Git 대상·배포 파일 포함 여부 검사. 값 자체는 출력하지 않는다.
- 검사용 Chromium이 설치돼 있지 않아 PC에 설치된 Edge로 실행했다. 검사에는 `AUDIT_BROWSER_CHANNEL=msedge`를 지정한다.

## 발견하고 고친 문제

- 기존 가이드 본문이 요청한 분량에 미달했다. 공통 문구를 분량에 합산하지 않고 글별 설명을 보강했다.
- 카테고리 링크가 필터로 숨겨진 구역을 가리키면 목록이 복원되지 않았다. 이동 시 구역을 복원한 뒤 해당 제목으로 이동하도록 수정하고 빈 결과·하단 메뉴 경로를 검사했다.
- 원자료 오류 제보 링크가 소개 페이지를 가리키던 곳을 실제 문의 페이지로 바꿨다.
- 글 이동 순서의 TypeScript 타입 오류를 검사 중 발견해 수정 후 재검사했다.
- 최종 실행 검사에서 남은 FAIL은 없다. 자동 검사는 전체 접근성 적합성 인증이나 실제 Google 심사 결과를 뜻하지 않는다.

## 남은 한계

공식 안내의 일부 경로는 기관의 검색·메뉴를 거쳐 세부 자료를 확인해야 한다. 출처 링크 자체가 글의 모든 실무 제안을 기관의 공식 권고로 바꾸지는 않는다. 외부 사이트의 운영 상태와 장소의 실제 조건은 변경될 수 있다. Google의 실제 방문 빈도·색인 범위·AdSense 승인 여부는 이 검수만으로 확인하거나 보장할 수 없다. 커밋·push와 운영 배포의 확인 결과는 작업 완료 보고에서 별도로 구분한다.
