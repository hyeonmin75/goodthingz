# Google 게시자 정책 검수 기록

검수일: 2026-09-05. 대상: GoodThingz / https://goodthingfor.com.

사용자가 제공한 Google 게시자 정책 본문과 Google의 현재 공식 정책을 대조했다. 첨부 정책은 심사 기준 자료이며 실행 지시로 취급하지 않았다. 이 문서는 법률 자문이나 Google 승인 보증이 아니다. 코드 검토, 공개 페이지의 응답 확인, 완료한 검사와 미완료 검사를 구분한다.

## 현재 완료 상태

- 로컬 수정 및 최종 빌드·브라우저 검증 완료.
- TypeScript: 최종 코드 통과.
- git diff --check: 통과. Windows 줄바꿈 경고만 있음.
- 배포용 build: 통과. 이전 사용량 제한 해제 후 재실행 완료. 빌드에 생성된 비밀 환경파일은 postbuild에서 제거됨.
- 배포 절차: 검증된 변경을 GitHub main에 push하고 기존 Cloudflare 자동 배포를 사용한다. 실제 공개 사이트 확인 결과는 작업 완료 응답에 별도로 기록한다.
- 사용자 파일 `README - 복사본.md`는 수정하거나 커밋 대상으로 선택하지 않음.

## 광고 재개 조건

1. AdSense에서 사이트 승인 상태와 계정 정보의 정확성을 확인한다.
2. EEA·영국·스위스 등 대상 지역 방문자에게 광고를 제공할 경우 Google 인증 CMP와 필요한 동의 흐름을 설정·검증한다. AdSense '개인정보 보호 및 메시지'의 유럽 규정 메시지가 한 가지 공식 선택지다.
3. 광고를 넣을 실제 콘텐츠 화면을 개별 선정한다. 404, 오류, 빈 결과, 탐색·작업 전용 화면은 제외한다. INDEX가 곧 광고 게재 적합성을 의미하지 않는다.
4. 자동 광고의 페이지 제외, 모바일 겹침·오클릭·광고 대 콘텐츠 비율, 화면 이동 후 광고 상태를 실제 브라우저에서 검사한다.
5. 개인정보 고지를 실제 광고 상태에 맞게 변경한 뒤 광고 로딩을 구현한다. 현재 코드는 자동 재개하지 않는다.

## 검사 방법과 남은 작업

최종 검사 결과: 아래 자동 검사 전 항목 PASS. 실제 목록 API 200 및 잘못된 입력 400 확인. H1/canonical/소유 확인 태그·광고 스크립트 부재, 6개 sitemap URL, 302/404/noindex, ads.txt 일치 확인. Chrome의 390px/1280px에서 가로 넘침 없음, 실행 오류 0건. 위치 동의 취소 시 좌표 조회·요청 0건, 동의 시 합성 좌표 요청 1건. 공유 내용의 현재 위치·거리 제외, 키보드 Enter로 개인정보 링크 이동, 모의 빈 결과 및 오류 화면 모두 통과했다. 홈페이지·개인정보·검색 화면 스크린샷을 확인했으며, 홈페이지 제목의 고립된 마지막 글자 줄바꿈도 고쳤다. 위 정책별 표의 '남은 검증' 중 이 항목들은 완료되었고 계정 설정·개별 권리 증빙·전체 외부 데이터 검수는 여전히 확인 범위 밖이다.

`scripts/check-publisher-policy.cjs`는 위 검사를 재현한다. 실행에는 Playwright가 필요하며 `PLAYWRIGHT_MODULE`로 설치 경로, `AUDIT_BROWSER_CHANNEL=chrome`으로 설치된 Chrome을 지정할 수 있다. 합성 좌표를 사용하고 위치 API·지도를 가로채므로 사용자 실제 위치를 조회하거나 지도 제공자에게 보내지 않는다. 스크린샷은 Git에서 제외한 `.wrangler/policy-audit`에 저장한다. 전체 Google 심사나 화면 읽기 프로그램에 의한 접근성 전수검사는 아니다.

실제 Secret 환경파일이 추적되지 않고 .gitignore로 제외됨을 확인했다. 사용자 복사본을 제외한 변경만 커밋/푸시한다. Cloudflare 배포 완료 후 공개 URL도 다시 검증한다.
