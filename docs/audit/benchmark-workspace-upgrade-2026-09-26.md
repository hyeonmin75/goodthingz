## 새 이미지와 화면 구성

- 현재 제공되는 내장 GPT 이미지 생성 도구(`image_gen`)로 새 일러스트를 생성했다. 도구 결과는 세부 모델 버전명을 반환하지 않으므로 특정 모델 번호를 임의로 기재하지 않는다.
- 장면: 이동장·물그릇과 함께 여행을 준비하는 반려견. 특정 장소의 실제 사진, 입장 허가, 현장 취재 자료로 사용하지 않는다. 기존 실제 장소 사진은 계속 제공기관·이용조건을 표시한다.
- 원본 비율을 유지해 WebP로 최적화했다. 1536×1024 약 239KiB, 768×512 약 77KiB. 그림 내용은 코드로 합성·변형하지 않았다.
- PC는 넓은 소개 영역 안에서 검색과 그림을 함께 배치하고, 태블릿·모바일은 그림을 아래로 옮겨 글과 검색창 뒤의 복잡한 무늬를 피한다. 배경 그림에 과도한 어두운 덮개를 넣지 않는다.
- 실제 텍스트는 이미지에 넣지 않고 HTML로 제공한다. 제목·검색·메뉴는 키보드와 읽기 도구로 접근할 수 있다. 새 파일 이름을 사용해 이전 이미지 캐시와 구분한다.
- 기존 Pretendard/Gmarket Sans와 청록색 기본 체계를 유지하고, 구역 메뉴·상태에는 장미색·파란색·황색을 보조로 사용한다. 그라데이션·광고성 수치·큰 장식 카드는 추가하지 않는다.

## 방문 준비 보드의 기능 계약

1. **확인 현황**: 후보마다 기존 4개 확인 항목을 세며, 분모는 `후보 수 × 4`이다. 입장 성공률·장소 품질 점수·자동 허용 판정이 아니다. 비어 있는 계획은 0/0으로 표시한다.
2. **남은 일**: 사용자가 기록한 조건 불일치를 먼저 표시하고 미확인을 이어서 보여준다. 전체·미확인·불일치로 좁힐 수 있다. 화살표를 누르면 해당 선택 상자로 이동하고 키보드 초점도 옮긴다.
3. **비교표**: 후보별 4개 상태를 같은 행에서 비교한다. 표의 상태를 누르면 편집할 항목으로 이동한다. 작은 화면에서는 표 안에서만 좌우 이동하고 페이지 전체는 가로로 넘치지 않는다.
4. **CSV 내려받기**: 엑셀 등에서 열 수 있는 비교표. 장소명·공개 주소·확인 상태만 포함한다. 개인 메모·예산·방문 날짜·현재 위치를 제외하고, 셀 값이 실행 수식으로 해석되지 않도록 위험한 시작 문자를 처리한다. 기존 전체 계획 JSON 파일과 구분한다.
5. **변경 보호**: 저장하지 않은 변경을 표시하고 내부 페이지 이동 및 새로고침·문서 이동 때 경고한다. 저장 실패 시 저장 완료로 표시하지 않는다. 브라우저 강제 종료·기기 장애까지 복구하는 자동 저장 기능은 아니다.
6. **호환성**: 기존 v1 계획 파일, 저장한 장소 추가, 수동 후보 입력, 순서 변경, 공유·비용·인쇄 기능을 유지한다. API와 Secret 구조는 변경하지 않는다.

키워드와 유형을 함께 사용하는 검색은 기존 Adapter 정책을 따른다. 키워드 API에서 받은 현재 페이지를 유형으로 좁히는 경우, 화면에 기존 제한 안내와 페이지 이동을 유지한다. 필터 뒤의 전체 전국 수량을 계산했다고 주장하지 않는다.

## 검증과 남은 위험

추가 검사 `npm run test:workspace`는 실제 생성 파일 표시, 첫 화면의 다음 영역 노출, 검색 조건 전달, 집계·우선순위·필터·키보드 탭, 편집 초점, 저장 후 복구, CSV 개인정보 제외·수식 방어, 저장 실패 및 변경 유실 경고를 검사한다. 새 디자인은 360/768/1280/1920px에서 캡처한다.

최종 배포용 빌드를 로컬 Worker에서 실행해 다음 결과를 확인했다. 자동 검사 통과가 Google의 콘텐츠 심사 통과를 뜻하지는 않는다.
